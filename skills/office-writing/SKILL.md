# 職場文書寫作技能

## 通用原則
- 繁體中文、台灣用語（例：「訊息」不是「信息」、「品質」不是「質量」、「軟體」不是「軟件」）。
- **結論先講**：第一段就說目的或結論，細節放後面。
- 日期寫法：2026/11/24（週二）；時間 14:00。金額加千分位與幣別：NT$ 12,500。
- 使用者沒給的資訊（人名、日期、數字）**不要自己編**，用【待填：xxx】標出來。
- 寫完後列出：需要使用者確認或補充的地方。
- 預設把結果直接貼在回覆裡；使用者要檔案時，用 `word-docx` 技能輸出 .docx。

## Email
```
主旨：【事由類別】一句話說明重點（例：【確認】11/28 出貨數量調整）

○○ 您好，

（第一段：來信目的，一兩句）
（第二段：細節，多項就用 1. 2. 3. 條列）
（第三段：需要對方做什麼、期限）

如有任何問題，再麻煩告知，謝謝。

○○○ 敬上
```
- 對客戶/主管用「您」；對同事可較口語但保持禮貌。
- 回覆抱怨信：先致歉/理解 → 說明原因 → 處理方式與時間 → 再次致歉。

## 會議記錄
```
會議名稱：
時間：2026/xx/xx xx:xx–xx:xx　　地點：
主持人：　　記錄：　　出席：
一、討論事項
  1. 議題：……
     結論：……
二、待辦事項
  | 項目 | 負責人 | 期限 |
三、下次會議：
```
從逐字稿或筆記整理時：刪掉閒聊，每個議題只保留「討論重點 + 結論」，待辦一定要有負責人和期限（沒有就標【待確認】）。

## 週報 / 工作報告
```
本週完成：（條列，有數字就寫數字）
進行中：（項目、進度 %、預計完成日）
問題與需要的協助：
下週計畫：
```

## 簽呈（內部請示）
```
主旨：為○○○，擬請 核准○○○，請 鑒核。
說明：
  一、緣由：……
  二、內容：……（費用、期程、廠商）
  三、效益：……
擬辦：奉核後，由○○部依說明辦理。
```

## 公告 / 通知
標題 → 生效日期 → 內容（條列）→ 注意事項 → 聯絡窗口。

## 摘要整理（看完文件後）
1. 一句話總結
2. 3~5 個重點（條列）
3. 與使用者有關的行動項目、期限、金額
先用對應技能（pdf / word-docx / excel-xlsx / powerpoint-pptx）讀出內容，再整理。
